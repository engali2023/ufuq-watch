# أفق · معدّل الساعات الإسلامية

ساعة ثلاثية الأبعاد تفاعلية بتصميم إسلامي مع إمكانية تخصيص المعدن والقرص والحزام.

## ✨ المميزات
- تصميم هندسي إسلامي على القرص
- تغيير معدن العلبة بلمسة واحدة
- تبديل الحزام بسلاسة متحركة
- وضع AR لتجربة الساعة على المعصم
- أرقام عربية وأسماء أطوار القمر

## 🚀 التشغيل
افتح `index.html` في متصفح حديث يدعم WebGL.

## 🛠 التقنيات
- Three.js 0.160
- Canvas API للنصوص الإجرائية
- MediaPipe Hands لتتبع اليد
